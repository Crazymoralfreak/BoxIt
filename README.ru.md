# BoxIt

[English](README.md)

Архиватор. Окно, командная строка и самораспаковывающийся модуль пользуются одним движком: распаковка везде одна и та же, целиком или никак, с одними и теми же проверками имён и теми же пределами. Повреждённый архив не оставляет полузаписанную папку.

Интерфейс доступен на немецком, английском, испанском, французском, японском, корейском, польском, португальском, русском, турецком и китайском (упрощённом) языках. Учётной записи нет. В сеть BoxIt обращается только по кнопке **Проверить обновления**.

## Скачать

Последняя версия лежит на странице [релизов](https://github.com/Crazymoralfreak/BoxIt/releases/latest).

Windows, x64:

- `BoxIt_<версия>_x64-setup.exe` — установщик. Ставит BoxIt текущему пользователю, права администратора не нужны.
- `BoxIt_<версия>_x64-portable.zip` — портативная версия. Распакуйте папку `BoxIt` куда угодно и запустите `BoxIt.exe`. Пустой файл `portable` рядом с программой означает, что настройки, журналы и временные файлы она хранит в папке `data` рядом с собой.

Тег также собирает установщик Windows ARM64, образы диска macOS (Apple Silicon и Intel) и пакеты Linux `.deb` и AppImage (x64 и ARM64). Меню Проводника есть только в Windows. На macOS образ подписан локально, без сертификата Apple, поэтому Gatekeeper спросит перед первым открытием.

Файлы не подписаны сертификатом подписи кода, поэтому Windows SmartScreen при первом запуске покажет предупреждение.

## Что умеет

- **Открытие.** ZIP, 7-Zip, TAR, GZIP, BZIP2, XZ, Zstandard, LZ4, RAR, CAB, ISO, AR, CPIO, LHA и WIM. Имя вроде `notes.tar.gz` — это сжатый tar, а не один файл gzip. Перетаскивание, диалог или файл в командной строке.
- **Создание.** ZIP, 7-Zip, TAR и перечисленные выше сжатые tar и однофайловые форматы. Степень сжатия, метод, словарь, потоки, сплошной архив, комментарий и разбиение на тома.
- **Пароли.** ZIP и 7-Zip можно зашифровать, в том числе спрятав имена. Сохранённый пароль попадает в диспетчер учётных данных Windows, а не в папку данных. На macOS и Linux пароль спрашивается снова.
- **Распаковка.** Весь архив, одна папка или выделение. Новая папка с именем архива, папка, где лежит архив, или выбранная папка. Если файл уже есть: спросить, пропустить, заменить или оставить оба. Символические ссылки создаются только когда ведут внутрь папки назначения.
- **Проверка и восстановление.** Проверка читает каждый файл. Восстановление записывает то, что ещё читается, в новый архив и не трогает повреждённый.
- **Изменение архива.** Добавить или заменить файлы. Конвертировать в другой формат, не распаковывая на диск. Сравнить два архива по имени, размеру и контрольной сумме. Искать подстроку, маску `*` / `?` или регулярное выражение `re:`. Оценить размер будущего архива по образцу.
- **Несколько сразу.** Очередь с паузой и отменой. Проверить или распаковать список архивов. Две панели, просмотр (F3) и правка файла из архива (F4).
- **Самораспаковывающиеся архивы.** Windows-программа `.exe` из архива ZIP или 7-Zip и файла `boxit-sfx.exe`.
- **Windows.** Ассоциации файлов и меню в Проводнике, включая меню Windows 11: открыть, распаковать здесь, распаковать в папку, добавить в архив, сжать и отправить. Метка из интернета на архиве копируется на извлечённые из него файлы. Установленная копия умеет обновлять себя; портативная только сообщает, что вышла новая версия.

## Командная строка

`BoxIt.exe` — это и командная строка. Если первый аргумент — команда, окно не открывается. `boxit-cli` — та же программа с консолью: терминал её дожидается, и она может спросить пароль.

```
BoxIt list photos.7z
BoxIt extract photos.7z -o photos
BoxIt create backup.tar.zst documents projects --level maximum
BoxIt test backup.tar.zst
BoxIt repair broken.zip -o fixed.zip
BoxIt help
```

Ещё команды: `update`, `convert`, `diff`, `find`, `estimate`, `batch`, `bench`.

- `--json` печатает результат для скриптов. Текст для человека берётся из языка интерфейса и может меняться от версии к версии.
- Коды выхода: `0` готово, `1` ошибка и ничего не осталось наполовину, `2` командная строка не понята, `3` готово, но часть записей пропущена, `130` остановлено по Ctrl+C.
- `BoxIt.exe` — оконная программа, поэтому интерактивные `cmd` и PowerShell её не ждут. В скрипте ждите явно: `start /wait BoxIt.exe ...` в `cmd` или через канал в PowerShell. `boxit-cli` этого не требует.

## Что нужно

- Windows 10 или Windows 11, x64 или ARM64. Среда WebView2: в Windows 11 она есть, установщик приносит её, если её нет. Портативная копия без неё не запустится.
- macOS 11 или новее, Apple Silicon или Intel.
- Linux x64 или ARM64 с GTK и WebKitGTK 4.1.

## Данные

Настройки, список недавних архивов и журналы лежат в `%AppData%\BoxIt` в Windows, в `~/Library/Application Support/BoxIt` на macOS и в `$XDG_DATA_HOME/BoxIt` (или `~/.local/share/BoxIt`) в Linux. Портативная копия хранит их в папке `data` рядом с программой. Окно одно: второй запуск отдаёт свои файлы первому.

## Сборка

Нужны Node.js 20.19 или новее (или 22.12 и новее) и Rust 1.98 или новее.

```
npm install
npm run tauri build
```

В Windows установщик — `target\release\bundle\nsis\BoxIt_<версия>_x64-setup.exe`. Портативная копия — папка `portable\BoxIt`: `BoxIt.exe`, `boxit-cli.exe`, `boxit-sfx.exe`, `boxit_shell.dll` и пустой файл `portable`. Git эту папку не берёт.

```
npm run portable
```

## Выпуск версии

1. Поставьте новый номер версии в `package.json`, `src-tauri/tauri.conf.json` и корневой `Cargo.toml` (`[workspace.package]`).
2. Зафиксируйте изменения и пометьте коммит тегом `v<версия>`, например `v0.0.1`.
3. Отправьте тег на GitHub.

Тег запускает `.github/workflows/release.yml`. Он собирает установщик Windows x64, портативный архив и `latest.json`, а также пакеты для остальных систем. `latest.json` читает установленная копия. Портативная копия себя не подменяет.

Приложение ставит только обновление, подпись которого совпадает с открытым ключом в `src-tauri/tauri.conf.json` (`plugins.updater.pubkey`). Закрытый ключ хранится в секрете GitHub Actions `TAURI_SIGNING_PRIVATE_KEY`. Подпись включает `src-tauri/tauri.release.conf.json`, и только у сборки релиза.

## Проверки

```
npm run typecheck
npm run i18n:check
cargo fmt --all --check
cargo clippy --workspace --all-targets
cargo test --workspace
```

`scripts/check-i18n.mjs` проверяет, что у каждого словаря те же ключи и те же `{placeholders}`, что у `ru.json`. То же проверяет `crates/boxit-engine`, и ещё что у каждого кода ошибки есть текст.

## Состав

- `crates/boxit-core` — модель архива, имена, пределы. Без файлов.
- `crates/boxit-security` — имена, ссылки, папка назначения.
- `crates/boxit-codecs` — чтение и запись форматов. Единственный крейт с `unsafe`.
- `crates/boxit-engine` — открытие, распаковка, создание, очередь, настройки, тексты.
- `crates/boxit-cli` — командная строка.
- `crates/boxit-sfx` — самораспаковщик Windows.
- `crates/boxit-shell` — меню Проводника Windows 11.
- `src-tauri` — окно.
- `src` — интерфейс на React и TypeScript. Словари лежат в `src/i18n`.
