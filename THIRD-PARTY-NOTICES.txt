UnRAR
-----

BoxIt reads RAR archives with UnRAR, the source code published by the author
of RAR, Alexander Roshal (https://www.rarlab.com/rar_add.htm). BoxIt uses it
unmodified, as packaged by the `unrar_sys` crate, and only to list, test and
extract RAR archives. BoxIt does not create RAR archives, and this code may
not be used to make it do so.

A copy of BoxIt built without the feature `rar` has none of this code in it
and does not open RAR archives.
